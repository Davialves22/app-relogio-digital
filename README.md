⏰ Relógio Digital - Android

Aplicativo Android desenvolvido em Java utilizando o Android Studio, que exibe a hora atual em tempo real através do componente TextClock. O usuário pode capturar a hora exibida e apresentá-la em um TextView ao pressionar um botão.

🚀 Funcionalidades
Exibição da hora atual em tempo real.
Captura da hora exibida no TextClock.
Exibição da hora capturada em um TextView.
Interface simples e intuitiva.
Layout desenvolvido com ConstraintLayout.
🛠️ Tecnologias utilizadas
Java
Android Studio
Android SDK
ConstraintLayout
TextClock
Material Design
📱 Demonstração

O aplicativo possui uma interface com:

Relógio digital em tempo real;
Botão para capturar a hora atual;
Área para exibir a hora capturada pelo usuário.
📂 Estrutura do projeto
MainActivity.java – Lógica principal da aplicação.
activity_main.xml – Interface gráfica.
drawable/ – Recursos visuais (background).
values/ – Strings, cores e temas.
🎯 Objetivo

Este projeto foi desenvolvido com fins de aprendizado, praticando conceitos fundamentais do desenvolvimento Android, como:

Manipulação de componentes da interface (UI);
Eventos de clique (OnClickListener);
Utilização do TextClock;
Comunicação entre componentes da interface;
Organização do código em métodos.
